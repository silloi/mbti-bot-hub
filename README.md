# MBTI Bot Hub

あなたの分身が、あなたに足りない4人を連れてくる。

Grok Bot で動くマルチボットチームです。ユーザーが自分のMBTIを伝えると、窓口ボット（分身）が、分析家・外交官・番人・探検家の4グループから1体ずつ相性のいいボットを選んで自動作成します。課題を窓口に1つ投げると、反論・発想・実務・実行の視点で検討し、1つにまとめて返します。

10/11 Grok Bot Tokyo Hackathon 提出作品。

## 構成
- 窓口：MBTI Bot Hub（ユーザーの分身。中継とまとめだけを担い、命令や判定はしない）
- 仕様Skill：[`skills/mbti-team-spec/SKILL.md`](skills/mbti-team-spec/SKILL.md)（16タイプの役割表、説明テンプレート、推奨チーム、運営ルール）
- INTJユーザーの例で作られたチーム：[`bots/`](bots/)
  - ENTP 討論者：反論
  - ENFP 運動家：発想
  - ISTJ 管理者：実務
  - ESTP 起業家：実行

## 使い方
1. MBTI Bot Hub を追加し、あいさつに自分のMBTIを4文字で返す（わからなければ4問で推定）。
2. 窓口が相性のいい4体を理由つきで提案し、作成する。
3. 窓口に課題を1文で送る。
4. 各ボットが役割どおりに答え、窓口が結論・論点・次の一手にまとめて返す。

## 設計の工夫
- MBTIを性格判定ではなく、「唯一の仕事／やらないこと」つきの役割仕様として使う
- ボットを分けることで記憶と指示が独立し、反論役が本気で反論できる
- 境界ルールと「意見が割れたら1回だけ応答」で、馴れ合いと無限議論を防ぐ
- 本人と同じタイプは入れない（分身が担うため）
- 外部送信・予定変更・購入はしない。判断はユーザーに残す
