## 2. 回答案

### 作品名（推奨：MBTI Bot Hub）
- MBTI Bot Hub（現名。機能がひと目で伝わる）
- Mirror & Squad
- 16 Persona Studio
- ジブンの分身と4人の仲間
- Type Team Builder

### キャッチコピー（推奨：1）
1. あなたの分身が、あなたに足りない4人を連れてくる。
2. 性格診断を、チーム採用に。
3. ひとりで悩む時間を、4つの視点との会議に。

### 短い要約（約100字）
あなたのMBTIから「分身」の窓口ボットと、分析家・外交官・番人・探検家から1体ずつ選んだ相性チームを自動で作成。課題を投げるだけで、反論・発想・実務・実行の視点がそろった答えが返ってきます。

### 詳しい説明（約400字）
【課題】AIに相談すると、答えはいつも同じ視点に偏りがちです。かといって複数のボットを自分で作り、役割を決め、質問を配って回答をまとめるのは手間がかかります。
【仕組み】MBTI Bot Hubは、ユーザーのMBTIを引き継いだ分身の窓口ボットです。16タイプの役割表と編成ルールをもとに、分析家・外交官・番人・探検家の4グループから1体ずつ、ユーザーと相性のいいチームを自動で作ります（本人と同じタイプは分身が担うので入れません）。課題を受け取ると窓口が各メンバーに中継し、役割ごとの回答を集めて、ユーザーの視点で1つにまとめて返します。外部送信や予定変更はせず、判断はユーザーに残します。
【嬉しいこと】一人で考えていると抜けがちな視点を、課題を1つ投げるだけで補えます。自分の性格に合った伝え方でまとまるので読みやすく、チーム作りの手間もゼロです。

### 工夫した点
1. MBTIを「性格の当て物」ではなく「唯一の仕事／やらないこと」つきの役割仕様に変換した。診断の正しさに頼らず分業が機能する。
2. 1体に「多角的に」と頼むのではなく別ボットに分けた。記憶と指示が独立するので、反論役は本気で反論し、実務役は発想を広げない。
3. 境界ルール（新案を広げるのはENFP、既存案の検証はENTPなど）と「意見が割れたら1回だけ応答」で、馴れ合いと無限議論の両方を防いだ。
4. ユーザーは窓口1体と話すだけ。チーム作成も中継も自動で、メンバーは窓口から頼まれたときだけ動く。
5. 編成ルールを16タイプ表としてスキルに明文化し、再現できるようにした。初回に本人と同タイプを入れた誤りを見つけ、「本人と同タイプは入れない」をルール化して再発を防いだ。

### 使い方
1. テンプレートのリンクから MBTI Bot Hub を追加する。
2. 窓口ボットのあいさつに、自分のMBTIを4文字で返す（わからなければ4つの質問で推定）。
3. 窓口が相性のいい4体を理由つきで提案し、そのまま作成してサイドバーに並べる。
4. 窓口に課題を1文で送る。各ボットに直接話しかける必要はない。
5. 窓口が4体に配り、各自が役割で答え、割れた論点は1回応答し合う。
6. 窓口が結論・論点・次の一手を1つにまとめて返す。続きもそのまま窓口へ。

## 3. 資料の下書き

### 2分デモ動画台本
- 0:00-0:15 つかみ。一人でAIに相談する画面。「AIの答え、いつも同じ視点になっていませんか？」
- 0:15-0:35 セットアップ。Hubに自分のMBTIを伝え、窓口＋4体がサイドバーに並ぶ。「タイプを伝えるだけで、相性のいい4体が自動でそろいます。」
- 0:35-0:50 課題を投げる。「新サービスの集客、最初の1か月で何をする？」
- 0:50-1:25 チームが動く。「反論担当は穴を突き、発想担当はアイデアを、実務担当は計画とリスクを、実行担当は今日できる一手を出します。」
- 1:25-1:45 まとめ。窓口の統合回答。「全員の意見を、あなたの視点で1つにまとめます。」
- 1:45-2:00 締め。「一人で考える時間を、チームで考える時間に。MBTI Bot Hub。」
- 補足：同じ課題を単体ボットとチームで並べ、チームだけが出した指摘を1つ見せると説得力が増す。

### 審査で聞かれそうな質問と答え
- MBTIは科学的根拠が弱いのでは？ 正しさは主張せず、役割を分ける共通言語として使っている。
- 1体に多角的に頼めば同じでは？ 1体だと自分の案を甘く採点しがち。独立したボットなので本気で反論できる。
- 4体も作るのは手間では？ 作成は自動で、ユーザーは窓口1つと話すだけ。
- 相性の選び方は恣意的では？ 選定ルールをスキルに明文化して再現できる。
- 窓口のまとめで少数意見が消えるのでは？ 割れた論点は消さずに併記する。
